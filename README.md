# 🎨 Animated Portfolio

A modern, animated personal portfolio website built with React and Tailwind CSS.

## ✨ Features

- Smooth animations and transitions
- Responsive design across all screen sizes
- Modern UI components with Tailwind CSS
- Clean component architecture with React

## 🏃 Run Locally

```bash
git clone https://github.com/saikommera/animated-portfolio.git
cd animated-portfolio
npm install
npm start
```
